# Carelink Web — «Тихая забота» (Calm Care)

## North star
Семейное приложение заботы: телефоны, здоровье, доступ близких. Интерфейс должен ощущаться спокойным, надёжным и человечным — как хороший семейный врач. Никакой агрессивной рекламы, минимум декора, ясная иерархия. Весь UI-текст — на русском языке.

## Colors (light)
- Primary: глубокий хвойно-зелёный #1F5C4A (кнопки, активные состояния, ссылки). On-primary #FFFFFF.
- Primary container: #DCEFE6, текст на нём #0B3726.
- Secondary: тёплый песочный #8A6A3B (бейджи «Хранитель», акценты), container #F6EBDD.
- Tertiary: спокойный сине-серый #3E5F7A (информационные подсказки), container #E3EEF7.
- Background: #F7FAF8, Surface (карточки): #FFFFFF, Surface-variant: #EEF3F0, Outline: #C3CCC7.
- Text: основной #14201B, вторичный #4A5650 (контраст ≥ 4.5:1 на белом).
- Success #2E7D4F, Warning #A86200 (фон #FFF4E0), Error #B3261E (фон #FCE8E6).

## Typography (Cyrillic-safe)
- Заголовки: Manrope 600–700. H1 32/40, H2 24/32, H3 20/28.
- Текст: Inter 400/500. Body 16/24, Small 14/20, Caption 12/16.
- Цифры кодов (OTP, slug) — Inter tabular, моноширинный вид, крупно 24–28.

## Shape & spacing
- Скругления 12px для карточек и полей, кнопки 12px, бейджи — pill.
- 8-point grid; отступы карточек 24–32px; максимальная ширина контента 1200px; формы входа — центрированная карточка 440px.
- Тени минимальные (0 1px 2px rgba(20,32,27,.06)), разделение тоном фона, а не жирными рамками.

## Layout (web, desktop-first, responsive)
- Публичные экраны (вход, онбординг, восстановление, приглашение по ссылке): слева узкая панель бренда (логотип Carelink — сердце в домике, тёплая иллюстрация семьи, 1 строка ценности), справа карточка формы. Над формой — степпер шагов, если сценарий многошаговый.
- Приложение после входа: левый сайдбар 248px (логотип, переключатель семьи, пункты: Главная, Семья, Приглашения, Заявки, Уведомления, Профиль, Устройства и сессии, Безопасность), верхняя панель (поиск, колокольчик с бейджем, аватар). Контент — карточки на светлом фоне.

## Components
- Кнопки: primary (заливка #1F5C4A), secondary (контур), tertiary (текст), destructive (#B3261E). Высота 48px, фокус — кольцо 3px #8CC9B0.
- Поля: подпись над полем, подсказка под полем, ошибка красным с иконкой; поле OTP — отдельные ячейки.
- Баннеры состояний: info / success / warning / error с иконкой и действием.
- Бейджи ролей: «Хранитель» (песочный), «Участник» (зелёный светлый). Статусы приглашений: «Отправлено», «Ожидает принятия», «Принято», «Отклонено», «Истекло».
- Пустые состояния: мягкая линейная иллюстрация, заголовок, 1 строка пояснения, основное действие.
- Загрузка: скелетоны карточек, спиннер в кнопке.
- Доступность: WCAG AA, видимый фокус, крупные цели клика, не только цвет для статуса (иконка + текст).
